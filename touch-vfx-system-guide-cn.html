程序化 VFX 工具包

程序化生成的視覺特效 — 支援 UI 畫布與世界空間座標

為 UI 加入視覺回饋：

Assets → TouchEffectSystem → Prefabs → TouchEffects

將任一特效預製體加入場景畫布並解除封裝，例如 TouchInkTrail

檢查 InputController → InputSystemType 是否與專案相符，設為 Old 或 New

完成。執行場景測試 — 特效將作為輸入的回應出現

生成 UI 特效預製體（獨立於輸入）

Assets → TouchEffectSystem → Prefabs → TouchEffects → PreviewEffect

複製預製體，替換 Glow Material 與 Sparkle Particle Prefab，或直接使用原版

透過「實例化（Instantiate）」在所需情境中生成預製體

生成 3D 世界特效預製體（獨立於輸入）

Assets → TouchEffectSystem → Prefabs → WorldEffects，選擇預製體：

  • URP：使用 URP_VFXRadialSparks
  • 其他渲染管線：使用 VFXRadialSparks

複製預製體，替換 Glow Material，或直接使用原版

透過「實例化（Instantiate）」在所需情境中生成預製體

自訂材質與支援

每種特效中的 Glow Material 皆為使用系統自訂著色器建立的材質。你可以以此為基礎建立自己的著色器與材質，或作為開發者與我們聯繫以取得客製化解決方案。我們隨時樂意提供協助，也歡迎回饋以改進程序化 VFX 工具包（Procedural VFX Toolkit）。
