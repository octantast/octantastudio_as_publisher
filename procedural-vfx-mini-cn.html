概覽

程序化 VFX 迷你版是一組免費的程序化生成視覺特效。每個特效都是獨立的四邊形（quad），繪製一個動畫著色器。可在任何位置實例化它 — 於 UI 畫布、2D/3D 世界空間 — 無論您如何旋轉它。支援 URP、HDRP 與 Built-in 管線。特效透過 RenderTexture 渲染，保持輕量並與渲染管線無關。每個播放週期都會生成獨特的形狀：同一個特效播放兩次，看起來永遠不會完全一樣。如需功能更豐富的系統，請探索此進階版本。

使用方式

內附的預製體即為範本。在您需要它們的時刻與情境中生成它們。

將資產套件匯入您的 Unity 專案。
開啟 Assets → OctantaStudio → ProceduralVFXMini → Scenes → DemoScene 並按下 Play，以預覽世界空間與 UI 上的所有特效。
從您自己的程式碼生成特效。
  • 世界空間：在特效應出現的位置呼叫 Instantiate(effectPrefab, position, rotation)。
  • UI：將預製體實例化為 Canvas 的子物件，並設定其錨定位置。
  • 從 Prefabs → Templates 挑選預製體。URP 專案請使用 URP_ 前綴；HDRP 或 Built-in 則使用不帶前綴的版本。
特效於生成時播放並預設循環。若要改為一次性，請在預製體上取消勾選 Loop — 此時 Destroy On End 選項即會變為可用，且預設為啟用。

自訂

每個著色器都會在檢視面板中將其參數公開為滑桿、顏色與切換開關。選取特效所使用的材質，以互動方式調整外觀 — 無需撰寫程式碼。

調整特效

  • 在場景中選取該特效，並在檢視面板中開啟其 Glow Material。
  • 調整顏色、數量、速度、大小與其他參數 — 場景執行期間變更會立即套用。
  • 儲存到預製體的變更會在重新生成或重新啟動場景時生效。現有實例會保留先前的數值。

建立您自己的特效

  • 從 Prefabs → Templates 開啟任一範本，並將其 Glow Material 替換為使用 Shaders 資料夾中任一個著色器所建立的材質。
  • 在 Project 視窗中複製調整好的範本（Ctrl+D / Cmd+D）並重新命名。
  • 將新的預製體移至您自己的資料夾。它立即可用。

建立您自己的著色器

將內附的著色器作為範本以建構您自己的，然後將其材質套用以實驗新的特效。下圖展示套用於平面網格的著色器材質。

核心元件

GlowMeshPlayer.cs

透過將幀 blit 至 RenderTexture 並將結果顯示於 MeshRenderer 上，驅動世界空間特效。處理循環、一次性播放、週期之間的暫停，以及播放速度。

ParticlePreviewPlayer.cs

GlowMeshPlayer 的 UI 對應元件。透過 RawImage 與每實例 Material 於 UI 層播放著色器特效 — 用於將 VFX 疊加於按鈕、卡牌或升級上。

著色器

  • 全部 12 個著色器皆位於 Assets → OctantaStudio → ProceduralVFXMini → Shaders。
  • 每個著色器都會在檢視面板中將其參數公開為滑桿、顏色與切換開關。
  • 每個週期皆產生新的隨機種子，因此同一特效絕不會兩次看起來完全相同。
