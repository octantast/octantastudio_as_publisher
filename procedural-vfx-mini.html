Overview

Procedural VFX Mini is a free set of procedurally generated VFX. Each effect is a self-contained quad that renders an animated shader. Instantiate it anywhere - on the UI Canvas, in 2D/3D world space - however you rotate it. It works with URP, HDRP, and Built-in pipelines. Effects are rendered through a RenderTexture, keeping them lightweight and pipeline-agnostic. Every playback cycle generates a unique shape: the same effect played twice never looks identical. For a more feature-rich system, explore this advanced asset.

Usage

The included prefabs are templates. Spawn them at the moment and in the context where you need them.

Import the asset package into your Unity project.
Open Assets → OctantaStudio → ProceduralVFXMini → Scenes → DemoScene and press Play to preview all effects in world space and on the UI.
Spawn effects from your own code.
  • For world space: call Instantiate(effectPrefab, position, rotation) wherever the effect should appear.
  • For UI: instantiate the prefab as a child of your Canvas and set its anchored position.
  • Pick prefabs from Prefabs → Templates. Use the URP_ prefix in URP projects; non-prefixed in HDRP or Built-in.
The effect plays on spawn and loops by default. To make it one-shot, uncheck Loop on the prefab - the Destroy On End option then becomes available and is enabled by default.

Customization

Every shader exposes its parameters as sliders, colors, and toggles in the Inspector. Select the material used by an effect and tune the look interactively - no code required.

Adjust an effect

  • Select the effect in the scene and open its Glow Material in the Inspector.
  • Adjust color, count, speed, size, and other parameters - changes apply immediately while the scene is running.
  • Changes saved to a prefab take effect on respawn or scene restart. Existing instances keep their previous values.

Create your own effect

  • Open any template from Prefabs → Templates and replace its Glow Material with a material created from one of the shaders in the Shaders folder.
  • Duplicate the tuned template in the Project window (Ctrl+D / Cmd+D) and rename it.
  • Move the new prefab into your own folder. It is ready to use right away.

Core Components

GlowMeshPlayer.cs

Drives a world-space effect by blitting frames into a RenderTexture and displaying the result on a MeshRenderer. Handles looping, one-shot playback, pause between cycles, and playback speed.

ParticlePreviewPlayer.cs

UI counterpart of GlowMeshPlayer. Plays a shader effect on the UI layer through a RawImage and a per-instance Material - use it to overlay VFX on buttons, cards, or upgrades.

Shaders

  • All 12 shaders are located in Assets → OctantaStudio → ProceduralVFXMini → Shaders.
  • Each shader exposes its parameters as sliders, colors, and toggles in the Inspector.
  • Every cycle generates a new random seed, so the same effect never looks identical twice.
