概述（Overview）

Dynamic Photo Camera Mini 是一个简单易用的 Unity 游戏内摄影资产，专为侦探任务、调查玩法和互动系统设计。演示版本包含一个基础场景，玩家可以在其中拍照。如果你需要完整的调查系统和更多高级功能，请查看完整版资产。

技术信息（Technical details）

  • 基于 Unity 2022.3.20f1 (LTS) 开发。
  • 已在 Windows 10 PC 上测试（不支持移动端）。
  • 单张照片数据大小：约 25–26 KB。拍摄的照片存储在 Application.persistentDataPath。
  • 资产默认设置为 3D，并已在 3D 与 2D 模式下测试可正常运行。
  • 仅使用 Unity 标准组件与类，无额外依赖。

安装设置（Setup）

将资产包导入你的 Unity 项目。
将 PhotoController 预制体（Prefab）拖入场景。
摄像机设置（必需）
  • 在 Inspector 中，将你的主游戏摄像机指定给 InputController，然后选择其一：
    • 关闭预制体中的摄像机；
    • 或保留预制体摄像机，并关闭你自己的摄像机。
  • InputController 组件中的 Current Camera 字段必须指定摄像机。如果未指定，系统将自动使用 Camera.main。

使用指南（Usage Guide）

  • 按住鼠标点击 / 触摸 1 秒，直到方形动画结束。
  • 照片会出现在收藏中，并在多次游戏会话之间保存。
  • 点击 × 按钮即可删除照片。

核心组件（Core Components）

PhotoController.cs

主系统控制器，负责照片拍摄、收藏管理和文件操作。

PhotoUIManager.cs

处理 UI 功能、照片交互、图库显示和视觉反馈。

InputController.cs

跨平台输入系统，自动适配 PC / 移动端、2D / 3D（若支持）。

PhotoPrefab.cs

控制每一张照片卡片行为的脚本。

PhotoInputBlocker.cs

将此组件添加到任意按钮上，可防止误触拍照。需要在 Inspector 中设置 PhotoController 的引用。

常见问题（Common Issues）

UI / Canvas / 界面问题

⛔ 问题：照片无法响应输入。原因：PhotoController 预制体自带 Canvas，可能与现有 UI 重叠。

✅ 解决方案：解包（Unpack）预制体，并将 UI 内容合并到现有 Canvas 中，或反向操作。

输入系统（Input System）

⛔ 问题：使用新输入系统时出现错误：“InvalidOperationException: You are trying to read Input using the UnityEngine…”。

✅ 解决方案：进入 Edit → Project Settings → Player，将 Active Input Handling 设置为 Both。

⛔ 问题：拍照输入与现有逻辑冲突（例如按按钮就触发拍照）。

✅ 解决方案：使用 PhotoInputBlocker.cs。将其添加到相关按钮上，并在 Inspector 中绑定 PhotoController。

演示场景（Demo Scene）

⛔ 问题：测试场景中的材质或贴图未正确加载。

✅ 解决方案：所有示例物体的材质和贴图都位于 Materials 文件夹。默认使用 Standard Shader。如果使用 URP，请将 Shader 改为 URP/Lit 或与你的渲染管线兼容的 Shader。

创意（Ideas）

  • 用相机看清隐藏在黑暗中的东西。
  • 通过对比案发现场的照片以及物体状态的变化，可以判断这里事件发生的时间段。
  • 拍下不该拍的东西，可能会唤醒古老的力量。
  • 为任务寻找并拍摄地点。
  • 暗中调查，获取照片证据。
